# Cruzador de Placas

Página usada na disciplina **Ferramentas Tecnológicas e Plataformas de Apoio** (CIAR) para ensinar análise de rotas com câmeras OCR.

Você seleciona os CSVs da Consulta Radares, um por ponto da rota, e a página mostra as placas que passaram em todos os pontos. Ela também mostra como a lista encolhe a cada ponto e o trajeto de cada placa encontrada.

- Funciona direto no navegador, sem instalar nada.
- Os arquivos escolhidos são lidos só no computador de quem usa. Nada é enviado para servidor nenhum.
- O botão **Usar exemplo (Caso 1)** carrega uma base **fictícia** de treino (corredor DF ↔ Ponta Porã, "bate e volta").

**Não publique dados reais neste repositório.** Ele é público; aqui entram só a página e os dados fictícios do Caso 1.
